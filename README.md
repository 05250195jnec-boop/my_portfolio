# Sangay Wangmo | Personal Portfolio

A modern, interactive, and fully responsive personal portfolio website built from scratch using **HTML5, CSS3, and Vanilla JavaScript**. 

This portfolio serves as a digital resume, showcasing my background, skills, academic projects, and verified certifications. It features a premium dark/light theme, interactive animations, and a gamified user experience.

## 🌐 Live Demo
Check out the live website here: **[https://05250195jnec-boop.github.io/my_portfolio/](https://05250195jnec-boop.github.io/my_portfolio/)**

## ✨ Key Features

- **Interactive Particle Background:** A custom HTML5 Canvas network of moving particles that react to your mouse and spawn new connections when you click anywhere on the screen.
- **Animated Profile Orbit:** A floating profile picture surrounded by spinning dashed rings and glowing, color-coded skill badges (Web Design, Networking, Linux, Python).
- **Dark / Light Mode:** A fully functional theme toggle that saves the user's preference in `localStorage`.
- **Background Music:** A custom music player button (bottom left) that plays/pauses a background track.
- **Dynamic Project Filtering:** A smooth filtering system to sort projects by category (Web, Backend, Networking).
- **Interactive Certificates:** A clean grid showcasing certificates with hover effects and full-size preview links.
- **Responsive Design:** Carefully crafted layouts (Flexbox and CSS Grid) that look perfect on desktops, tablets, and mobile phones.
- **Form Validation:** A fully functional contact form with custom JavaScript validation and error messaging.

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, Vanilla JavaScript (ES6+)
- **Icons:** Custom SVG & Emojis
- **Fonts:** Google Fonts (`Outfit` for headings, `Inter` for body text)
- **Hosting:** GitHub Pages
